# Changelog

All notable changes to this project will be documented in this file.

## [0.3.0] - 2025-11-07

### Added
- Phase 4: Story Content Creation (All 8 Chapters)
- Complete story implementation with all character arcs
- Full quest system with main and side quests
- NPC dialogue trees and interactions

### Phase 3: Party System
- Four main characters: Kai (Venus), Ember (Mars), Aria (Mercury), Zephyr (Jupiter)
- Character-specific Psynergy abilities
- Progressive character acquisition system
- Character relationships and growth rates

## [0.2.5] - 2025-10-20

### Added
- Journal system for tracking story events
- Progressive party formation mechanics
- Story event logging and replay

## [0.2.0] - 2025-10-15

### Added
- Phase 2: Narrative Framework
- Story management system
- Quest tracking system
- Dialogue tree system with branching conversations
- Cutscene system for story sequences
- Character relationship tracking
- Party management for up to 4 characters

### Changed
- Enhanced game state management for story progression

## [0.1.0] - 2025-09-01

### Added
- Phase 1: Technical Foundation
- Core game engine using Flutter and Flame
- Turn-based battle system
- Psynergy system with 13+ abilities
- PP (Psynergy Points) resource management
- Save/load system with 3 save slots
- Inventory and shop systems
- Retro GameBoy/GBA color palette modes
- Audio management system
- Player character with stats and progression
- Monster database with level scaling
- Basic UI with retro aesthetic

### Technical
- Project structure and architecture
- Flutter SDK integration
- Flame game engine setup
- State management with Provider
- JSON serialization for save data

## Project History

### 2025-08-15 - Project Inception
- Initial project setup
