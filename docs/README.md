## 📝 Documentation Standards

All documentation in this project follows these standards:
- Written in Markdown format
- Includes table of contents for longer documents
- Uses clear headings and structure
- Contains code examples where relevant
- Maintains consistent formatting

## 🔄 Keeping Documentation Updated

When making significant changes to the codebase:
1. Update relevant documentation in this directory
2. Update CHANGELOG.md in the project root
3. Update Implementation Status if completing features
4. Keep README.md in sync with major changes
